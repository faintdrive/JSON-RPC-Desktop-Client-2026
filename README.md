<h1 align="center">JSON RPC Desktop Client</h1>

<p align="center">
  <b>Powerful client for testing and interacting with JSON-RPC APIs on Windows.</b>
</p>

---

## What This Tool Does

- Send JSON-RPC requests to any endpoint
- Full request customization (method, params, headers)
- Response visualization with syntax highlighting
- Batch request support
- Request history and collections
- Environment variables for dynamic requests
- Import and export configurations
- Works on Windows 10 and Windows 11

JSON RPC Desktop Client is a professional tool for developers who need to test, debug and interact with JSON-RPC APIs. It provides full request customization, response visualization and request management in a clean interface. This is a fully functional application with no limitations.
